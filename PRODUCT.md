# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Owner-specified React + TypeScript + Vite, Tailwind, shadcn/ui and Recharts over a loopback-only FastAPI adapter to the existing Python engine. Streamlit remains a fallback. No cloud services or external database dependency; versioned local SQLite stores public state.

## Users

Solo project owner presenting an independent pharmaceutical R&D portfolio to researchers and non-ML colleagues. Professional audience may include GPO colleagues; no GPO affiliation or endorsement.

## Product Purpose

Operate and explain retrospective screening: select compounds under a simulated budget, wait for delayed results, update decisions, compare independent policies and inspect scientific evidence.

## Operating Context

Windows desktop localhost, 1440px presentation and 390px mobile. One-address production mode, offline after initial installation, CPU only. English-only interface, including browsers with a legacy Thai preference. Primary tasks are scenario configuration, sequential laboratory simulation, comparison and audit/export.

## Capabilities and Constraints

Preserve private oracle isolation, event-derived metrics, fixed models and historical benchmark evidence. Historical HIV labels differ from simulated operational assumptions. Single-class and unseen-controller-state fallbacks must be visible. No claims of drug efficacy, GMP compliance, useful RL transfer or operational Digital Twin. Normal push to the original repository is owner-authorized after release gates; no public deployment or company systems.

## Brand Commitments

Existing CuraLoop-RL logo, teal #087F72, midnight #16333B and amber #B66914. User explicitly requests premium scientific workbench, restrained mint/off-white/stone, real scientific content, accessible typography and shadcn/dashboard references. The existing licensed bundled font must work offline.

## Evidence on Hand

Actual previous Git release dca5c81; historical 1200-molecule derivative with hashes/license; 2 trained controller checkpoints, 50 saved benchmark runs, original tests/evidence. The 2026-11-04 Windows baseline reran 103 Python tests and 10 frontend tests successfully before integration. Previous evidence is preserved and identified separately from new QA.

## Product Principles

Operate a real simulation rather than decorate a mock dashboard. Show provenance at the point of interpretation. Keep pending, predicted and delivered outcomes distinct. Preserve results even when unfavorable. Make the owner's setup and presentation workflow simple.

## Accessibility & Inclusion

Responsive English labels, keyboard focus, semantic native controls and accessible headless primitives, non-color-only legends, reduced-motion support and intentional loading/error/empty states.

## Delegated decisions

The explicit owner request delegates implementation and QA autonomously and supplies a precise visual/functional master prompt. No additional style approval interview is needed. Session execution is code-led because the requested deliverable is a working localhost application with real evidence; no permanent workflow preference is inferred.

## Reviewed v2 research and pilot direction

CuraLoop-RL is a local workbench for auditable molecular-screening replay. The implemented product supports public historical/synthetic tasks, batch selection, delayed delivery, budget accounting, independent comparisons and export/recovery. It uses classical predictors and frozen synthetic-trained controllers. It does not currently ingest live laboratory results or run a multi-user commercial service.

The next research product is a reproducible study of pending-aware selection under deadlines and capacity limits. The first commercial hypothesis is an R&D pilot that combines local installation, permitted-data mapping, matched historical replay and an evidence report. New data adapters, scheduling extensions and customer workflows are planned work until tested.
