# LR-CF1 descriptive analysis freeze

Frozen before any confirmation-value analysis. This adds reporting detail to the
unchanged controls protocol; it does not create a confirmatory effect threshold.

Report every campaign, all five fixed budgets, five seeds and all 18 nominal
ranker/operator arms. Publish only aggregate cells: confirmation count, H, Murcko/
fallback D, fingerprint-sensitivity D, H/B and D/B. Never publish private compound
identities, structures, raw source rows, individual confirmation labels or PDFs.
Keep actual integer budgets alongside their nominal percentages.

Summarize each campaign/arm/budget by the five-seed arithmetic mean, sample standard
deviation and observed minimum/maximum. These describe conditional algorithm/tie
variation; they are not biological population confidence intervals. Report all
four provider blocks, the one historical annotation-connected component and the
lack of an independent biological replication claim. Equal-campaign means of
H/B and D/B are descriptive across these six fixed campaigns. Provider means are
shown separately; no p-value or population interval is calculated.

Show paired seed-wise differences for each diversification operator versus the
same ranker's top-ranked arm, and for every arm versus MVS-A top-ranked. Report
both H and D, including negative differences. A cell is nondominated only when
no other arm has H at least as large and D at least as large with one strict
improvement. Retain ties as ties. Calculate these empirical frontiers separately
for each campaign/budget/seed and for five-seed campaign means. They are observed
baseline frontiers, not an attainable future-method oracle.

Use the 10% budget only as a labelled descriptive reading example; display all
five budgets in the evidence tables and curves. No outcome-based choice of
budget, group definition, campaign, seed, model or highlighted success is allowed.
The fixed fingerprint grouping is a sensitivity, not a replacement endpoint.
Avoid pooling seeds as independent campaigns or counting shared targets as
independent biological families. Source confirmation 0 includes inconclusive;
unperformed/missing confirmation is outside U, never filled with 0.

The next-method decision is qualitative and owner-reviewed. If common fixed
diversification controls already account for useful tradeoffs, recommend NO_GO
for a new-selector claim. Residual ranking/coverage differences alone cannot
establish novelty, independent generalization or publication readiness. Any
mechanism proposal stays untrained, separately budgeted and subject to owner
approval. Offline product and English paper artifacts distinguish implemented
baseline evidence from proposed capabilities regardless of the result.
