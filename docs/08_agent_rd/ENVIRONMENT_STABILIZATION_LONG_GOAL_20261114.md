   state and bounded loader traces. Distinguish verified cause from hypothesis.
2. Fix launcher prerequisites and result persistence before substantive work.
   Separate builder and worker, lock complete artifacts and start a fresh

   development canaries 12/13/71/72 using unchanged reference/scoring, at most one
