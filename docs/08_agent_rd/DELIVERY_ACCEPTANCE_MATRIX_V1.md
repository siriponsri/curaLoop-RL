## Product policy repair and scientific fidelity

The frozen numerical verifier can accept true aggregate values while a model
fails a refusal or completeness task. The negative development probe exposed
this before locked evaluation; it remains in all reports. The product now adds
a separate deterministic capability preflight at the API boundary. It uses
the existing strong deterministic capability rule and conservative Thai phrase
rules, records an explicit controller refusal and can export it without a model
call. These rules are not a general language-intent classifier. Real protection
still comes from the closed data/tool interfaces, not matching a few words.

This service repair is outside `src/curaloop_rd/agent_rd`, does not change the
frozen experimental prompts/engine/cases/scoring and is not a new comparative
research candidate. Post-study policy/replay tests use their own receipts and
no new model generation. One separate current-service real-model mission ran
after the matrix exited, within the same original phase/deadline. It completed
three real calls, persisted and recovered across restart, but failed its task
with terminal ABSTAINED. The lifecycle PASS is not task success. Its receipt is
product-current-model-acceptance-v1.json. No replacement trial was run. A
controller's0-call denial is not a model refusal, and the product's newer policy
does not replace failed frozen P observations.

The demo should show three honest tasks: an original recorded real-model
comparison, a current deterministic five-budget sweep and a current explicit
unsupported-request denial. Fixed source metadata and the existing local MCP
transport remain available. Live paper/database intake, a generic business
agent, team-tool writes, deployment and journal submission are not performed.

## Final decision rule

Completion requires the actual product, immutable experiment dispositions,
audited analysis, reviewed documents/figures, complete return/cleanup and main
delivery. It does not require an LLM win. An incomplete matrix yields a complete
inconclusive report with every planned unit shown; it does not authorize a
positive claim, a new model or more data. A competitive journal submission is a
separate owner decision based on the delivered evidence and venue requirements.
