## Failures and corrections retained

1. The first native container failed before its reference process started:
   a nested gold-results mountpoint could not be created beneath a read-only
   parent mount. Its inspection, failed job and CPU booking remain intact.
2. The first repair transport failed a source-hash assertion because text
   transfer normalized Windows line endings. The final transport sent exact
   bytes. No reference outcome was repeated by that transport repair.
3. The initial adapter misread `eval()` as a scalar. Upstream returns
   `(success, log_info)`. Its nominal false flags were **unsupported-interface
   states, not scientific failures**. Existing successful-reference outputs
   were rescored without refitting. Both reports remain available.
4. Initial dependency setup retained failures, including a large optional
   Torch dependency hitting the isolated temporary-storage cap and conflicts
   with the chosen pandas version. No Torch model weights were downloaded.
5. One bounded, source-supported compatibility batch applied the upstream
   pandas/RDKit/matplotlib/pymatgen version bounds to the four failed reference
   programs. Successful original references were not refitted. Remaining
   problems included `mdf_forge`, `fau_colors` and other program compatibility
   failures. This final batch still did not reach four qualified source groups.

The native interface was checked against
[upstream compute_scores.py at the captured commit](https://github.com/OSU-NLP-Group/ScienceAgentBench/blob/c26e151ed601ba109dc4d35e057ff8e73fec469d/compute_scores.py).
Environment bounds came from
[upstream run_eval.py at the same commit](https://github.com/OSU-NLP-Group/ScienceAgentBench/blob/c26e151ed601ba109dc4d35e057ff8e73fec469d/run_eval.py).
Original predicate bytes were preserved. This is an adapted isolated execution
wrapper; it omits CodeBERT and paid rubric/image grading and is not a full
upstream harness reproduction.

This failure concerns bounded environment/reference readiness. It does not
reject the version-binding hypothesis or establish that the benchmark is invalid.
The primary effect is unknown, not zero. Do not start another benchmark,
environment search, reference retry or external comparative study in this goal.
