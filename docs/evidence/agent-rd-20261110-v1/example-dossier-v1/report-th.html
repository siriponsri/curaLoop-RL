ขอบเขตและข้อจำกัด

  • ข้อมูลพัฒนาที่เปิดเผยแล้ว ยังไม่ใช่ผลยืนยันทางชีววิทยาจากชุดอิสระ
  • ตัดรายการที่ไม่มีผลยืนยันออก ไม่ถือเป็นผล inactive
  • กลุ่ม nonpositive ของแหล่งข้อมูลรวมทั้ง inactive และ inconclusive
  • ช่วงค่าจาก seed ห้าค่าเป็นการทำซ้ำภายใต้เงื่อนไขเดิม ไม่ใช่ช่วงความเชื่อมั่นทางชีววิทยา
  • หก campaigns อยู่ในกลุ่มเชื่อมโยง annotation เดียวกัน
  • ค่า D=H ของ round-robin เกิดจากกลไกการเลือกที่งบเหล่านี้
  • ยังไม่ได้วัดการประหยัดแล็บ ประสิทธิผลในการทดลองล่วงหน้า หรือประโยชน์ทางคลินิก
  • มีเฉพาะข้อมูลรวม ไม่มีรายการสารรายตัวหรือผลที่ซ่อนและผลที่ยังไม่ออก
  • ยังไม่ยืนยันสิทธิ์เชิงพาณิชย์หรือการเผยแพร่ข้อมูลดิบต่อ
  • CF1 ไม่ได้ประเมิน RL ส่วน simulator เป็นงานย้อนหลังอีกการศึกษาหนึ่ง
