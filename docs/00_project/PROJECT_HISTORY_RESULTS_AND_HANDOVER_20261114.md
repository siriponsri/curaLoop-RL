### 2.2 Units that must not be combined

- A molecular row is not necessarily a unique compound across assays.
- A campaign or seed is not a new biological family.
- An annotation-connected component is not a certified evolutionary family.
- A training branch, diagnostic fit, model response and complete agent mission
  are different units.
- A software test or browser view is not a scientific experiment.
- Reexecution by the same developer is computational reproducibility evidence,
  not independent scientific replication.
- Historical isolated AI-agent visual/UX reviews are not independent human
  expert or representative-user validation.
- A native reference-program check is not an agent success.

The report deliberately gives **no grand total of independent experiments** and
**no total-project measured CPU figure**. The existing records contain reused
panels, dependent seeds, technical retries, cumulative accounts and incomplete
measurement of administration. Adding their headline counts would misrepresent
the strength and cost of the evidence.

## 3. Project destination and changes of research question

The enduring owner objective has been a useful solo pharmaceutical R&D
workbench plus a defensible computational research contribution. The owner
explicitly rejected a new-benchmark publication as the default destination.
Datasets are instruments for evaluating a method, not the intended contribution
merely because they were downloaded, filtered or reorganized. [S18] [S29]

The main research questions changed as evidence accumulated:

1. **Screening policy:** can an RL-style controller improve discovery under a
   fixed budget, pending observations and delayed deliveries?
2. **Event-time planning:** can valuing pending information and pruning search
   improve useful discovery or computation over strong cheap controls?
3. **Evidence-sensitive assay choice:** can papers and context metadata change
   a scientifically valid molecular or assay decision?
4. **Computation allocation:** can a learned controller choose REUSE, UPDATE or
   PLAN better than matched Greedy, periodic or threshold controls?
5. **Confirmation portfolio:** can selecting candidates for confirmation improve
   meaningful chemotype coverage beyond classical diversified controls?
6. **Agent reliability:** does an explicit evidence/source gate improve actual
   task completion over the same model and tools?
7. **Executable scientific checks:** do automatically created scientific checks
   improve scientific-code correctness beyond competent generic generated tests?

These are related product ambitions, but they are not one unchanged experiment.
Each has different data, controls, endpoints and limitations. A positive result
in one cannot rescue a failed gate in another without a separately justified
study.

with exact scientific agreement. This is valuable same-implementer
computational reproduction; it is not 108 new biological samples or external
scientific validation. [S07]

**Conclusion:** the implemented pending-awareness variants did not establish
the proposed deadline-discovery advantage in their fixed pilot.

## 8. Goal 2: real-data planning and pruning

A nonanticipative small-state reference and a partial-dispatch/WAIT planner were
implemented. A real-label Tox21 challenge executed **180/180 frozen runs** over
three endpoints, three seeds, two timing conditions and ten methods. These were
development simulations of historical outcomes, not new wet-lab assays. [S08]

| Method | Mean hits, common timing | Mean hits, heterogeneous timing |
| --- | ---: | ---: |
| Random | 0.333 | 0.222 |
| Frozen empirical-model Greedy | 0.444 | 0.444 |
| Updated empirical-model Greedy | 1.111 | 0.111 |
| Analytical posterior-mean Greedy | 0.889 | 0.778 |
| Nearest-hit | 2.444 | 2.000 |
| Cheap pending-cluster WAIT | 1.111 | 0.222 |
| CPE-inspired rollout | 1.111 | 0.667 |
| Unpruned hit rollout | 0.444 | 0.556 |
| Cardinality-pruned rollout | 0.444 | 0.556 |
| Content-pruned rollout | 0.444 | 0.556 |

The pruning implementations preserved the same selected actions and snapshots:
36 exact paired checks passed across 18 matched groups. However:

| Computational measure | Unpruned | Content-pruned |
| --- | ---: | ---: |
| Root actions considered | 458 | 458 |
| Root actions pruned | 0 | 13 |
| Continuation nodes | 14,196 | 14,144 |
| Summed policy time, seconds | 2.6687 | 3.3168 |
| Summed complete-run time, seconds | 16.4098 | 16.7802 |

Only 2.84% of actions were pruned. Policy time increased **24.3%**, and complete
run time increased **2.26%** in the one-pass timing comparison. The rollout's
mean hit difference versus nearest-hit was **-1.722**, observed paired range
[-6, +1]. The planner did not choose optional WAIT on these real-data runs.

**Disposition:** implementation/reference checks passed; a useful computation
or discovery advance did not. The finite-model bound is not a guarantee about
the true assay distribution, omitted actions or whole-campaign regret.
