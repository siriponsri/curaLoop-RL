## Predeclared construction

1. Authenticate every protection/exposure registry and carry forward all DQR
   canonical identities and inspected task/source dependencies. Resolve the
   already exposed planning molecule CHEMBL8809 from the pinned DB using the
   fixed structure role; retain canonical aliases and disposition. Never infer
   clean identity from absence of the exact ChEMBL ID. Unknown mapping blocks
   all proposed final use, while independent catalog work may continue.
2. Census the complete allowed catalog using ID counts; freeze aggregate
   counts and the reference-capable opportunity list. A raw molecule-ID count
   is an upper bound before canonical pruning. Keep Ki/Kd separate. A single
   assay/type cannot create multiple independent reference contexts by renaming it.
3. Select at most 500 targets with a nominal single-assay Ki/Kd reference of
   at least 128 IDs and a potential auxiliary context, using a predeclared
   hash for ties. Report all functional categories; do not force equal category
   quotas or favor a target by potency or value nonmissingness. Freeze this
   intent list before full graph/canonical checks, with no post-failure refill.
4. Include all eligible endpoint assays for an assessed target. Admit a target
   graph only when it fits the remaining assay/row/identity caps completely.
   An oversized target is `UNKNOWN_CAP`, not a complete prefix or a zero-support
   target. All unassessed catalog/intent targets remain visible in the denominator.
5. Close existing family, source DOI, assay-group, deposition/protocol and
   exposure links before any proposed evaluation role. Preserve inherited
   roles as provenance; conflicts quarantine new tasks. Do not relabel old
   final/validation records as training. Unknown new biological mapping stays
   UNKNOWN; existing family labels alone are not new certificates.
   Verify the namespace of assay-group/deposition keys before treating them as
   global IDs. Unknown identifier scope withholds final use; retain old graph
   constraints and do not infer procedure equivalence from a shared identifier.
6. Apply canonical protections/exposure exclusions and exact-identity ownership,
   then require 128/64/32 support. Search up to three auxiliary contexts exactly
   or record auxiliary-search incompleteness. A top-eight heuristic cannot
   certify that no eligible combination exists. Freeze at most 120 candidates;
   every candidate remains nominal and reference/procedure truth pending.
7. Accept no new pooled reference procedure. Record plausible pooling capacity
   only as a noneligible upper bound requiring later source concordance. Do not
   add endpoints, lower floors, change biological units or replace rejected cases.

Any rule implementation repair must preserve the frozen intent, source bounds
and activity blindness. No configuration search or biological redesign follows
automatically from a low yield. Record failures, code versions and reservations.
