## Why this endpoint

LR-D23 failed its learned-scheduler gate. The new question concerns actual
confirmation slots and assay-confirmed structural coverage. Published MVS-A/data
valuation resources provide direct baseline candidates; novelty and observation
support remain unresolved. The first useful result is therefore a trustworthy
baseline/coverage comparison on published data, before funding another selector.

The observable retrospective target is H(B), confirmed positives, and D(B),
prespecified structure groups with at least one confirmed positive, within a
declared eligible observation-supported universe. It is not whole-primary-library
value, clinical efficacy, validated lead-series discovery or monetary lab saving.

## Concrete comparison envelope

Up to six ranking controls: random, primary readout, MVS-A, RF, GBM and a
nearest-primary reference. Primary readout direction and the nearest reference
are fixed from source semantics before confirmation outcomes. RF/GBM may use
only legitimate primary/development training information; no current hidden
confirmation label becomes free training or validation data.

Each ranker receives the same three portfolio options: top-ranked selection,
ranked cluster-round-robin and a classical max-min diversity control. Freeze exact
tie rules, descriptors, empty-scaffold handling and operator implementations
before the first value calculation. These are baseline controls, not a new
algorithm contribution. If a control cannot be defined or reproduced with the
available source fields, report the limitation rather than choose a favorable
alternative after outcomes.

Five exploratory budgets are ceil({1,2,5,10,20}% of the supported universe),
converted to actual confirmation counts before value analysis. Merge duplicate
integer budgets; do not count them as extra evidence. Use five fixed seeds,
90101/90113/90133/90149/90163, for declared random/tie/model variation. There are
at most 6 x 6 x 3 x 5 x 5 = 2,700 portfolio cells. Cache legitimate ranks/features;
seed repetitions do not create new campaigns. Report all 18 nominal arms,
including redundant or ineffective diversified controls.

Primary grouping: a prespecified Murcko-scaffold operational definition with
explicit acyclic/empty cases. A fixed fingerprint-group sensitivity may test
definition dependence. Freeze it before confirmation values; do not tune the
threshold for a favorable coverage result. No full-library N-by-N similarity
matrix is required; profile bounded-memory implementations first.

The pilot is descriptive preparation. Report absolute H/D, paired campaign
effects, compute, group-size distribution and sensitivity. If defensible
independent campaign blocks are too few for population intervals, show all block
effects and conditional seed variation with that limitation. Do not relabel seeds
or overlapping dataset versions as biological sample size. No final16 access.

## What this goal would close

1. **Data and endpoint feasibility:** actual admitted/failed campaign register,
   source observations and identifiable claim boundary.
2. **Baseline and decision opportunity:** real published-data reproductions and
   matched confirmation/chemotype curves, including strong diversified controls.

Product receives an offline confirmation-plan/evidence report backed by those
results, without UI/runtime integration or customer-study claims. Journal work
receives methods/results and a defensible next question, without submission or
publication-readiness guarantees. Novel-method development and independent
evaluation remain later owner decisions. Raw data/PDFs/traces stay private.

Approval would authorize only this precise fresh budget, scoped source intake,
development baseline labels after gates, conditional stage continuation, complete
return/exact cleanup and normal main delivery. It would not reopen old grants,
activate conditional96h, access final16, train a new selector, connect live team
