## How to report progress

Use one status per task: OPEN, IN_PROGRESS, PASS_WITH_EVIDENCE, FAILED_WITH_EVIDENCE or BLOCKED_BY_NAMED_INPUT. A checked checkbox without an artifact is not a completion record. Describe a blocker narrowly enough that another workstream can continue. Model sophistication and file count are not acceptance criteria.

## Avoid premature expansion

Do not add molecular generation, a generic LLM chat window, multi-tenant hosting or a physical Digital Twin programme before the core research question is testable. These are possible separate products, not prerequisites for the selected paper and pilot. A scope change should identify what evidence it will produce and what it displaces.
