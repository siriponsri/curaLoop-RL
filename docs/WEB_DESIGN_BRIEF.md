# Web v0.2 design and functional contract

Mode: **Operate**. Owner delegates implementation, with a precise supplied master prompt; no aesthetic approval round is inferred. Build is code-led and reuses the existing logo/data/font. The chosen form is a research operations journal: a stable tool rail, a quiet publication-like workspace, explicit campaign state and inspectable evidence. Brand constraints outrank alternative styling.

## First viewport

The owner sees a clear screening decision, public historical-data badge, the live campaign counts, a genuine RDKit-rendered structure if available, and an action into the simulation. No stock-biotech fantasy, invented molecule, placeholder metric or institutional endorsement. The display headline and specimen explain that public structure and hidden assay outcome are separate channels.

## Direction and system

Teal #087F72 is the action/confirmed-feedback color, midnight #16333B the reading color, amber #B66914 the delayed-feedback/limitations color. Restrained mint, off-white and stone support white work surfaces. The existing licensed bundled Noto font serves the English interface offline. Icons come from Lucide, not emoji. Charts use labels and line patterns alongside distinct colors.

## Signature interaction

The live screening loop changes from eligible pool → accepted requests → pending feedback → delivered outcomes as the actual Python engine advances. The budget ledger moves units from available to reserved to spent. No artificial completion percentages or success animations. A deliberate width transition expresses real budget state; reduced-motion mode disables it.

## Cross-surface reach

Scenario builder uses validated native controls and an honest preview of assumptions. Compound explorer renders public structures and only revealed outcomes. Benchmark arena starts actual independent campaigns, polls a real CPU job and exports the complete public events. Research evidence distinguishes saved v0.1 results from current simulation; Q-learning/bandit historical fallback is explicit. Guided presentation operates the same live campaign.

## Responsive contract

1440px desktop with persistent sidebar; 390px mobile with accessible Radix navigation dialog. Natural document scroll, contained wide data tables and no page-level horizontal overflow. All seven routes work by direct URL in production mode. Busy, loading, error, empty, keyboard focus and restart states are meaningful.

## Evidence / boundaries

Code/benchmark/model hashes are preserved and verified separately from new app evidence. Only a documented metadata attribution bug is changed in the scientific service. No policy or budget semantics are reimplemented in JavaScript. Original Streamlit remains available. Windows scripts are supplied, but only the actual execution platform can be claimed tested.

Design references checked at pinned commits: shadcn/ui and Shadcn Dashboard; the shell is original, not a fork with fake CRM/finance data. The external style roll service was unavailable; the owner-pinned scientific workbench and grounded operations-journal composition govern the build. No generated mockup is used as product evidence.
