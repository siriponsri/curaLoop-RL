# Submission review package

**Prepared for author review; not cleared for submission and not submitted.**
Read [readiness](../SUBMISSION_READINESS_20261104.md), the
[journal shortlist](../JOURNAL_TARGETS_20261104.md) and reconciled
[manuscript](../MANUSCRIPT.md) alongside the immutable experiment reports.

The package contains [author metadata](author_metadata.json), an
[unsent cover letter](COVER_LETTER_DRAFT.md),
[availability draft](DATA_CODE_AVAILABILITY_DRAFT.md) and
[human declarations checklist](DECLARATIONS_CHECKLIST.md). It does not certify
author statements, close data rights or authorize payment.

A software-focused manuscript should explain the problem/related tools,
information/accounting contracts, implementation/recovery, reproducible usage,
measured development evaluation including null/unfavorable findings, reuse,
availability and limitations. Keep hypothetical simulations separate. The wider
12+ family evaluation remains future work until its gates and frozen execution
are complete.

After contribution, author, venue and rights review, assemble the journal's
editable Word/LaTeX source and supporting files, freeze the reviewed release and
obtain independent final review. Send only the explicitly approved package.
GitHub main publication is not journal submission or acceptance.
