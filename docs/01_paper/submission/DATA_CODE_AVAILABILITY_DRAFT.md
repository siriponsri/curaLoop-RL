# Data and code availability draft

First-party source is available from
https://github.com/siriponsri/curaLoop-RL under the repository's MIT license,
subject to retained third-party notices. The submitted manuscript must identify
the reviewed immutable commit/release; main is mutable. No archive DOI has been
assigned by this package.

The repository retains the historical HIV manifest, development configurations,
source receipts, preprocessing/overlap audits, campaign artifacts and analysis
outputs. NCATS development inputs are identified by AIDs 743122, 743140 and
720552, official source URLs and exact file/cohort hashes. Raw/full derived
candidate files, wheels and local environments are not in public Git.
Reproduction therefore requires permitted input retrieval and hash verification;
this draft does not promise an archived raw-data deposit that does not exist.

Candidate-preparation packets contain metadata facts, identifiers, hashes and
derived structure audits, without evaluated final-study outcome values. Prepared
LIT-PCBA/DeepChem datasets were not ingested. Public accessibility does not grant
blanket redistribution rights; third-party files retain their own terms.
Private reading-room PDFs and customer information are excluded.

Before submission, verify reviewer access to the minimum inputs for every
reported conclusion, complete applicable attribution/rights checks and cite a
new archive only after its identifier is assigned. Outstanding final-study data
gates remain open.
