# CuraLoop Research Desk: design brief

**North star:** the current scientific record is the focal point; its evidence
and next useful action are one step away.

The owner selected minimal/modern UI for both the screening app and C Workspace,
with EN/TH and restrained motion. Retain the supplied logo, bundled CuraThai font
and teal/midnight/amber identity from DESIGN.md. Use a light working canvas and
white surfaces. This is a design refinement of the current product, not a rebrand.

## Owner's no-slop refinement

The owner rejected the visual quality of the opened competitor examples and
explicitly selected [No Slop UI](https://github.com/LeoStehlik/no-slop-ui), whose
SKILL, banned-pattern list and review checklist were read before UI implementation.
Competitors supply workflow observations and weaknesses; their visual styling is
not the quality target. Public reference captures stay private research material.

Apply a content-first work surface: compact headings, stable navigation, readable
records, an optional source inspector and one clear primary action. Remove
dashboard marketing heroes, eyebrow headings, repeated KPI-card grids, nested
cards, excessive pills, decorative gradients/glows and filler slogans. Use6–8px
controls/surfaces,1px borders and14–16px working text. Keep the existing brand
and licensed Thai font. Functional counts and essential limitations remain.

The later no-slop instruction refines runtime motion: opacity/color transitions
around100–200ms; no hover transform, scale, bounce, sliding tab pill or entrance
choreography. HyperFrames remains the separate approved deterministic walkthrough,
whose scene transitions explain actual captured work without replacing controls.

## Public competitor research and design decisions

Only official public documentation/product imagery was inspected. No authenticated
account, workflow benchmark or competitor performance experiment was conducted.

| Reference | Observable/documented pattern | CuraLoop decision |
| --- | --- | --- |
| [Benchling navigation](https://help.benchling.com/hc/en-us/articles/9684267691021-Navigate-your-Benchling-account) | Stable project/object navigation, worklists and status-filtered work | Stable task navigation with campaign context; keep one primary action in view. |
| [Causaly Agentic Research](https://www.causaly.com/products/agentic-research) | Public presentations of cited outputs, supporting/contradictory evidence and gaps | Show a readable conclusion/gap beside an expandable source inspector. Guided metadata controls remain explicit. |
| [Dotmatics Luma](https://www.dotmatics.com/luma) | Separate workflow, summary and assay-record imagery | Separate overview from working records; avoid repeating a wall of KPI cards. |
| [Schrödinger LiveDesign](https://www.schrodinger.com/platform/products/livedesign/) | Spreadsheet/LiveReports, assay columns, forms/plots and selected-record context | Connect a readable record list with its details and visualization. Preserve pending/failed/unrun distinctions. |

The product's credible differentiation hypothesis is inspectable local replay
and evidence: budget commitments, delayed disclosure, source-bound claims, useful
blocked reports and portable identities. This is not a claim of enterprise ELN,
molecular-design, agent-quality or analyst-time superiority.

## Shared visual and interaction direction

- Use existing canvas#f7f9f8, white#ffffff, teal#087f72 and reading ink#16333b.
  Amber#b66914 communicates a qualification and always has a written label.
- Make the current campaign/record the first-screen subject. Reduce marketing
  headers, repeated badges and explanatory paragraphs. Keep source context,
  primary action and essential limitations visible; move exact hashes/IDs into
  an accessible inspector without removing them.
- Increase ordinary body/control readability; avoid relying on the old11px
  table/footnote density. Thai headings use natural spacing and sufficient leading.
- Keep navigation, language controls, field shapes, focus rings and source-detail
  behavior consistent across the two interfaces. Language persists across refresh.
- Preserve actual empty/loading/error/disabled/recovery states and form input.
  Translated wrappers may surround original source/backend details; source values
  and machine schemas remain canonical.

## Motion

Use opacity/color to explain selection, opening details and moving between work areas.
Runtime transitions are short, scoped and cleaned up; charts retain unanimated
discrete scientific data. Reduced-motion users receive the same complete state
without movement. The HyperFrames walkthrough uses actual redesigned UI captures,
brand/font rules from DESIGN.md and deterministic seekable GSAP timelines. No
fabricated discovery counts, success percentages or implied live AI process.

## Acceptance

Walk both languages at desktop/mobile and200%zoom. Verify language changes and
refresh retain the same campaign, revisions, queue and saved comparison; test
failure/recovery, focus and overflow. Verify C report identities and local exports.
Refresh actual screenshots and the English manual. Independent visual and fresh
UX reviews use current screens, with coverage/limitations recorded explicitly.
