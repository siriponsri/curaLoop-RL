# Four-screen pharmaceutical research dashboard

Owner direction: 8 November 2026. **PRODUCT IMPLEMENTATION; RESEARCH REMAINS PAUSED.**
shadcn Dashboard is the primary layout/component reference. Reuse the existing
React/shadcn-style primitives and Python API, without importing a starter project's
authentication, sample accounts, sales metrics or unrelated features.

Design intent: a calm pharmaceutical research dashboard where the current
campaign, observed outcomes and next action are clear at a glance. Preserve the
approved neutral Graphite/Copper identity and bilingual EN/TH operation. Reference
images guide hierarchy, workflow inspection, comparison and molecular browsing;
their illustrative numbers, protein views and commercial-product claims are not data.

| Screen | Main decision and live information | Required interaction/evidence |
| --- | --- | --- |
| Discovery Overview | Understand the current project: candidate pool, simulated budget, delivered actives, progress and active policy | Open the current lab, inspect a public 2D molecule, review event-derived progress and source identity |
| Digital Twin Simulation Lab | See Compound Selection -> Assay Queue -> Result Delivery -> Model Update | Interactive stage inspection and real engine select/advance controls; prominent Retrospective Simulator designation; update evidence only from delivered observations |
| Benchmark Arena | Compare Random, Greedy, uncertainty-based Active Learning and existing RL variants | Actual comparison outputs, discoveries/cost, recorded seed variability, model/fallback disclosure; no invented confidence intervals or new training |
| Compound Explorer | Search compounds, inspect public structure/status and selection history | Searchable table as default, optional grid, details and request/delivery history from the current run; unobserved and pending labels remain hidden |

Four primary navigation destinations; scenario, evidence, recovery and guided
presentation remain supporting tools. C Workspace stays available. No login or
fictional team/project roster is added.

Data contracts remain the current RunView/RunReport/Candidate/Evidence API.
Show simulated units, not currency or actual lab savings. Distinguish current
single-seed comparisons from the preserved ten-seed HIV record. SD belongs to
that recorded seed allocation; no variance is fabricated for one run. Missing
outcomes, synthetic data and controller fallback remain explicit.

Motion is short and functional: navigation transition, stage selection and
panel feedback. Respect reduced motion. Do not animate simulated progress
independently of engine events or turn pending predictions into observed hits.

Acceptance: existing persistence/recovery flows remain usable; loading, empty
and failure states work; EN/TH survives navigation and state changes; tables
and controls are keyboard accessible at desktop and mobile widths. Check actual
rendered screens and a real select -> pending -> delivered flow in an isolated
local test store. Source/type checks and relevant regressions are separate from
visual inspection. No new scientific comparison or protected-outcome access is
released by these product checks.
