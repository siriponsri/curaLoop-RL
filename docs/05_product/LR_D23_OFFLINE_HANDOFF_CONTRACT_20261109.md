# LR-D23 offline evidence handoff

This handoff supplies inspectable evidence to the existing EN/TH research
dashboard and offline R&D plugin design. It does not change the running UI or
connect a live tool. The versioned aggregate and decision card are produced at
closure, including a truthful early-stop disposition where applicable.

Consumers must display the experiment's development status, endpoint and
provenance alongside its figures. Use **Retrospective Simulator** in the
Simulation Lab. An assay positive is an observed retrospective label, not a
validated drug or clinical benefit. CPU seconds are computation, not laboratory
money. Keep strong fixed controls visible even when the learned candidate fails.

The four screens receive only aggregate evidence:

| Screen | Permitted evidence | Required distinction |
| --- | --- | --- |
| Discovery Overview | Six exposed development assays, four annotation components, observed experiment status | Not an independent final result or12-family benchmark |
| Digital Twin Simulation Lab | Delivered-event replay in a separately authorized runtime phase | Never expose the private Oracle or undelivered outcomes |
| Benchmark Arena | All assigned arms, CPU/discovery means, component effects and conditional seed intervals | Show failed gates and unrun D3 cells |
| Compound Explorer | Structures, selection history and delivered results only under the runtime's visibility contract | This aggregate handoff contains no compound-level rows or hidden assay values |

An adapter should validate the JSON schema before loading a card. Method status
and phase readiness are separate: an artifact can be valid while the scientific
candidate is inconclusive. Do not promote `PASS_EXECUTION` into efficacy.

Integration acceptance remains future work: connect actual engine events,
enforce hidden-label boundaries at the API, verify EN/TH rendering and navigation,
and measure a real team's workflow. No authentication scaffold, invented KPI,
paid model call, customer study, external write or deployment is included here.
