## A focused walkthrough

1. Establish the question: how does the team currently choose its next assay
   batch, and what information is still pending? Use an actual recent workflow
   only if the participant chooses to describe it. Do not request confidential
   structures or outcomes for an initial public-data demo.
2. Show the current local POC using the frozen public HIV replay. Identify
   historical activity labels versus assumed capacity, cost, delay and missingness.
   Keep the default seed and retain a zero-hit result if it occurs.
3. Select a batch in Simulation lab, inspect reservations and pending privacy,
   advance time and reconcile delivered results. Show the decision explanations
   and actual controller/fallback status without promising that a model will win.
4. Export one run, demonstrate validated resume/recovery, then show independent
   matched comparisons. Explain that comparison JSON and the CSV event ledger
   serve different purposes.
5. Review the proposed [pilot deliverables](PILOT_OFFER.md) and ask which concrete
   replay/reporting question matters to the team. Separate a useful conversation
   from an actual commitment. Agree further contact only with owner authorization.
