# CuraLoop-RL v2 brand artwork

Created 2026-11-04 with the built-in image-generation tool. These are AI-assisted
raster PNG assets, not editable vector masters or trademark-clearance evidence.
No external institutional mark or medical-emblem asset was used.

- `curaloop-logo-v2.png`: transparent horizontal wordmark; used by the application,
  Streamlit and the PDF cover. `frontend/public/brand/logo-v2.png` is an unchanged
  byte copy for the web build.
- `curaloop-readme-header.png`: opaque light-paper presentation of the same brand
  direction, used in the README so dark and light themes both retain contrast.
- Original `assets/curaloop-logo.png` and `frontend/public/brand/logo.png` remain
  unchanged. Earlier screenshots and scientific evidence are preserved.

The two open arcs and selected node express the candidate/feedback cycle. Teal,
midnight and amber follow the established project palette. These marks are
conceptual brand symbols, not molecular structures or biological evidence.

## Released master prompt

Use case: logo-brand. Create one finished premium horizontal logo lockup for
CuraLoop-RL, an independent scientific software workbench for retrospective
pharmaceutical screening. This replaces a basic circular-arrow logo with a more
distinctive, refined research identity. Genuinely transparent background.
Composition wide about3.6:1, full logo comfortably inside canvas with modest
optical margins. A compact original symbol at left: two precise interlocking open
arcs form an elegant C / continuous learning loop, with a restrained three-node
assay-selection motif integrated into the geometry and one small warm-amber
selected point. Sophisticated, balanced negative space, crisp geometric flat
vector-like edges, monoline consistency, strong silhouette at small sizes. No
literal medicine imagery. To its right a highly legible beautiful custom
contemporary sans wordmark reading EXACTLY 'CuraLoop-RL' (capital C and L, hyphen,
uppercase R L). Text must be accurate and fully legible, quiet premium scientific
typography, medium-to-semibold weight, carefully spaced rather than generic heavy
rounded type. Main ink midnight #16333B, core mark teal #087F72, one amber #B66914
accent only. Flat solid colors, no gradient, no shadow, no glow, no texture, no
mockup, no3D, no surrounding cards, no subtitle, no extra words, no institutional
emblems, no medical cross, no pill, no DNA helix, no trademark symbol. Aim for the
visual sophistication of a carefully commissioned modern research-tool identity,
original and restrained. Deliver only the single final transparent logo.

## Released README header prompt

Create a polished README header asset from this exact CuraLoop-RL logo. Keep the
existing clean teal two-loop symbol, amber point and dark midnight wordmark
unchanged in shape and spelling. Place it centered on a completely solid opaque
very pale cool-white #F7F9F8 rectangular background, with generous clean whitespace:
about10 percent margin on all sides, a wide3:1 canvas. This is a simple flat digital
brand header, not a mockup. No transparency anywhere; the entire background should
be uniform #F7F9F8. No texture, no rough edges, no shadows, no outlines, no added
title, no tagline, no extra text. Preserve the sharp, solid-filled logo contours.
The final exact wordmark remains CuraLoop-RL. Purpose: legible on both light and
dark GitHub themes.

Two experimental dark transparent recolorings failed edge quality and were
discarded. Only the clean master and opaque README header are released.
