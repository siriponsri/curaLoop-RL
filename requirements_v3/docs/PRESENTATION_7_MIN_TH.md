# Speaker notes — Portfolio Presentation (Thai)

**Slide / demo 1: ทำไมต้องคัดเลือกสารอย่างมีกลยุทธ์**

ตัวอย่างสมมติ: มีสารจำนวนมาก แต่จำนวนรอบการทดสอบจำกัด เป้าหมายของการเลือกสารในต้นแบบคือค้นหาสารที่ให้ผล Active ตาม assay ที่กำหนดให้ได้มากขึ้นภายใต้ข้อจำกัดเดียวกัน ไม่ใช่การค้นพบยาที่พร้อมใช้ในผู้ป่วย

**Slide / demo 2: ระบบประกอบด้วยอะไร**

Public/synthetic compound library → molecular features/predictor → decision policy → hidden result store → reveal outcome → update next decision → auditable dashboard

**Slide / demo 3: ทดลองให้ดูทันที**

เลือก scenario และแสดงผลหนึ่งรอบโดยเปิดเผยว่าเป็นการจำลอง ย้ำเรื่องไม่เห็นผลเฉลยล่วงหน้าและดูผลผ่าน event log

**Slide / demo 4: วิธีอื่นทำได้ดีแค่ไหน**

เปรียบเทียบ random, uncertainty, predicted-greedy ด้วยข้อมูลและงบประมาณเดียวกัน ระบุว่า 'ผลลัพธ์ของการทดลองนี้' ไม่ใช่คำรับรองในองค์กร

**Slide / demo 5: RL + Digital Twin ช่วยอะไรต่อ**

RL จะเรียนรู้การปรับนโยบายตัดสินใจในแต่ละรอบ ส่วน Digital Twin readiness คือการออกแบบโครงสร้างข้อมูลสำหรับจำลองสถานการณ์ต้นทุน/เวลา/ผลตอบกลับ และอาจรับข้อมูลจริงได้หลังมีสิทธิ์และกระบวนการตรวจสอบที่เหมาะสม

**Slide / demo 6: สิ่งที่ผู้สร้างลงมือทำจริง**

แสดง Git repo, tests, architecture, run report, reproducibility, ความโปร่งใสเรื่องข้อมูล พร้อมข้อจำกัดและ Roadmap

## Closing phrase

'โครงการนี้เป็นผลงานส่วนบุคคลที่ใช้ข้อมูลสาธารณะหรือข้อมูลจำลอง เพื่อสาธิตแนวทางการนำ AI มาช่วยจัดลำดับการทดลองในงานวิจัยและพัฒนายา หากจะนำไปใช้ในกระบวนการจริง จำเป็นต้องร่วมกับผู้เชี่ยวชาญและตรวจสอบความถูกต้องของข้อมูลและแบบจำลองเพิ่มเติม'
