# Handoff checklist — GPT Work to Codex (Portfolio Edition)

- [ ] Real application repository exists (not just the ZIP specification directory).
- [ ] Commit SHA and clean/dirty working-tree status are recorded.
- [ ] `python -m pip install ...`, test command, CLI and Streamlit launch are written and have actually been exercised.
- [ ] Offline synthetic fixture works with visible `SYNTHETIC_ONLY` badge/flag.
- [ ] Overview, Scenario Setup, Screening Run, Compare & Export are usable; no inert 'demo' controls.
- [ ] Oracle separation, duplicate accounting, budget and delay tests pass.
- [ ] 3 baseline policies truly run and charts derive from event data.
- [ ] `docs/PRODUCT_REQUIREMENTS.md` and `docs/DEMO_STORYBOARD_TH.md` reflected in new repo.
- [ ] No GPO affiliation claim, logo, internal data or unauthorized public repo push.
- [ ] Paper PDF count, origin and third-party rights truthfully stated.
- [ ] `HANDOFF_TO_CODEX.md` exists **inside new app repository**, containing status/evidence, next issues, blockers and exact commit.
- [ ] 5–7 minute presentation can be followed without RL/chemistry expertise.
- [ ] Owner reviews visibility, publication and any organizational IP/branding question before sharing.
